# Bike Sharing Data Analysis & Dashboard 🚲

## 📊 Project Overview

This project is a data analysis and visualization project based on the **Bike Sharing Dataset**. The analysis explores bike rental patterns based on various factors such as season, weather, working days, and time.

The project also provides an interactive dashboard built with **Streamlit** to visualize the analysis results.

## 🎓 Project Information

* **Project:** Bike Sharing Data Analysis & Dashboard
* **Course:** Belajar Analisis Data dengan Python

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Streamlit
* Jupyter Notebook

## ⚙️ Setup Environment

Create a new Conda environment:

```bash
conda create --name main-ds python=3.11
conda activate main-ds
```

Install the required dependencies:

```bash
pip install numpy pandas matplotlib seaborn jupyter streamlit
```

## 🚀 Run the Dashboard

Run the Streamlit application:

```bash
streamlit run dashboard.py
```

The dashboard will then be available through the local URL provided by Streamlit.
